# Session 4 — Demos: Type System

Teaching demos and tutorials that go with [session 4 of the curriculum](https://github.com/EK-Python-Elective/EK_DAT_Python_Elective_2026_fall/tree/main/04._type_system) (Type Hints, Dataclasses, and Pydantic).

Jupyter notebooks are handy for *exploring* code interactively — trying out a `dataclass` or a Pydantic model, inspecting types, seeing output cell-by-cell — which is exactly what session 4 is about. These tutorials cover two ways to run notebooks. (Notebooks are for exploration and demos; the project's real code still lives in `.py` files.)

## Tutorials

- [Jupyter notebooks in VS Code](jupyter-in-vscode.md) — set up and run notebooks inside the editor you already use.
- [Jupyter from the terminal, in the browser](jupyter-from-terminal-in-browser.md) — launch a notebook server with `uv` and work in your browser.

Both tutorials use `uv`, the same tool the course uses everywhere else (sessions 1 and 3).
